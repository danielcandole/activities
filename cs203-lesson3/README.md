# Canteen Cart Titan

A JavaScript program that creates independent canteen **cart titans** using closures, supports item management **(including titans)**, calculates totals with discounts, and sorts and filters items.

## How to Run

1. Make sure Node.js is installed.
2. Open a terminal in the project folder.
3. Run the following command:

```bash
node canteen_candole.js
```

The program will display the test results for Pieck's and Falco's carts in the terminal.
